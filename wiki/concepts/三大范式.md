# Agent自主驱动开发三大范式

## 范式对比

| 范式 | 核心模式 | 人工参与 | 适用场景 |
|------|----------|----------|----------|
| **Vibe Coding** | 对话式，人工逐行审查 | 高 | 快速原型、探索性开发 |
| **SDD（规格驱动开发）** | 规格先行，Agent 按规格实现 | 中 | 生产质量项目，吞吐量高 5-7 倍 |
| **自主 Agent 开发** | 最少人工干预的独立循环 | 低 | 持续迭代、成熟项目 |

## Vibe Coding

对话驱动的开发方式，人工逐行审查 Agent 输出。适合快速原型和探索性工作，但规模化困难。

## SDD（规格驱动开发）

规格先行：先写结构化规格（含验收标准），再让 Agent 按规格实现。吞吐量比 Vibe Coding 高 5-7 倍，是生产级项目的推荐范式。

> [!important] SDD 的关键
> 规格必须有明确的验收标准，不是模糊的提示词。验收标准是 Agent 和人类的契约。

## 自主 Agent 开发

最少人工干预的独立循环模式。Agent 自主规划、实现、测试，人类只做看门狗监控。适合成熟项目和持续迭代场景。
