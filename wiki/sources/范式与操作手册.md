# Agent自主驱动开发范式与操作手册

## 三大范式

- **Vibe Coding**：对话式，人工逐行审查，适合快速原型
- **SDD（规格驱动开发）**：规格先行，Agent 按规格实现，吞吐量高 5-7 倍
- **自主 Agent 开发**：最少人工干预的独立循环，适合持续迭代

## 新项目关键步骤

1. 写 CLAUDE.md / AGENTS.md（最关键！Agent 的入职手册）
2. 写结构化规格（有验收标准，不是模糊的提示词）
3. 拆成原子任务（1-2 小时/任务）
4. Agent 在独立 worktree 并行工作（看门狗监控）
5. 对照验收标准审查（不是逐行代码审查）

## 已有项目关键步骤

1. 逆向文档工程（Reversa）提取隐性知识
2. 补关键测试 + Seam Model 保护现有代码
3. 写 CLAUDE.md 传达隐性知识（禁区、临时方案、约定）
4. 渐进式接手（4 周过渡：第1周补测试→第2周小功能→第3周中功能→第4周起独立）
5. 禁止一次性全移交（失败率 > 60%）

> [!tip] 核心公式
> 好规格 + 好指令文件 + 好测试 + 好 CI = Agent 自动驾驶
