# Pi SDD 接手现有项目操作方案（摘要）

## 四阶段路线图

1. **阶段 0 安装验证**（30 分钟）：确认 Pi + Gentle AI + subagents 正常运行
2. **阶段 1 知识提取**（2-4 小时）：让 Agent 探索代码库、提取隐性知识、写 CLAUDE.md / AGENTS.md + openspec/config.yaml
3. **阶段 2 SDD 试运行**（1-2 天）：选一个小低风险变更跑完 SDD 全流程（onboard → full chain）
4. **阶段 3 日常循环**：每功能 = SDD full chain 或 plan chain → verify chain
