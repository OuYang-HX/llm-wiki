# Termux 配置备份同步到 GitHub
Termux 配置备份只保存配置文件（bashrc、termux.properties、ssh-config、pi-settings、herdr-config），不含包列表和安装脚本。仓库地址 git@github.com:OuYang-HX/termux-backup.git（Private）。字体和 SSH 私钥/API Keys 不放仓库，需手动处理。wiki 页面 [[Termux 配置备份]] 和 [[Pi-Agent安装配置（Termux）]] 已更新为引用 GitHub 仓库而非本地 /storage/emulated/0/Download/termux-backup/。
