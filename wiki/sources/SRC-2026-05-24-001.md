# Termux 环境迁移指南

> 源文件: 2026-05-24 从本机 Termux 环境完整导出的迁移备份指南。

## 摘要

本源记录了从一台 Android 手机完整导出 Termux 环境配置、在新手机上恢复的详细步骤。涵盖 224 个包的批量重装、Termux 键盘/字体配置、SSH 密钥、Pi Agent 全套配置（models/auth/settings/SDD agents/chains/extensions）、Herdr 终端复用器、Python/Node.js 工具链等。

## 关键实体与概念

- [[Pi-Agent安装配置（Termux）]] — Pi Agent 在 Termux 上的安装与配置详情
- Termux F-Droid 安装 — 必须从 F-Droid 安装，Play Store 版已过时
- `pkg_installed.txt` — 批量重装包列表，224 个包
- `termux.properties` — 自定义键盘布局（3 行额外按键，含中文标注）
- `font.ttf` — JetBrains Mono Nerd Font，TUI 图标支持
- `pi_auth.json` / `pi_models.json` — Pi Agent 认证和模型配置（含敏感密钥）
- Herdr — 终端复用器，编译二进制需重装，配置为 TOML 格式

## 迁移要点

1. **包重装**: `pkg install $(cat pkg_installed.txt) -y`，部分包可能已更名
2. **SSH 私钥未导出**: 安全原因，需手动传输或重新生成
3. **GitHub 需重新认证**: `gh auth login`
4. **Pi 配置直接复制**: models.json / auth.json / settings.json + agents/chains/extensions 目录
5. **Herdr 二进制需重装**: 配置文件可直接复制
6. **验证清单**: node/python/cargo/java/gh/ssh/herdr/pi 逐项确认
